🔑 Clé API Claude (Glow Up Coach)

Comment configurer ta clé API :

  1. Déploie ce site sur Netlify (glisse ton dossier sur netlify.com/drop)
  2. Dans Netlify → Site settings → Environment variables
  3. Ajoute une variable : ANTHROPIC_API_KEY = ta clé sk-ant-…
  4. Redéploie le site (bouton Trigger deploy)

🧪 Tester la connexion

Fonctionne uniquement une fois le site déployé sur Netlify avec la variable ANTHROPIC_API_KEY configurée.
